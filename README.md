# Vortex documentation
The documentation for Vortex.

## Documentation
```text
vortex-docs
├── content   # Documentation
│   ├── guides   # Guides and explanations for using Vortex Studio
│   └── reference   # API/reference documentation
│       ├── classes   # Instance classes
│       ├── datatypes   # Datatypes
│       ├── globals    # Pre-defined globals
└────────────────────
```

## Contributing
Vortex Documentation is open to contributions! If you want to document something that's part of the Vortex Scripting API but isn't currently covered, you can create an issue or open a pull request.

You can also contribute if you notice something that's missing, unclear, or incorrect.

See [CONTRIBUTING.md](./CONTRIBUTING.md) to learn how to contribute.

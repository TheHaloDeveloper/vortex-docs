## METHODS

:FromName(Name:String)
---
Gets the value of an enum from its name

:FromValue(Value:int)
---
Gets the value of an enum from its numerical index

:GetEnumItems()
---
Returns every item inside an enum

Value.Name
---
The Name of the enum value as a string

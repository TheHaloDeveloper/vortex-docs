## Constructor

### TweenInfo.new(time: `number?`, easingStyle: `Enum.EasingStyle?`, easingDirection: `Enum.EasingDirection?`, repeatCount: `number?`, reverses: `boolean?`, delayTime: `number?`): [`TweenInfo`](/reference/datatypes/tween-info/)

All arguments are optional.

```luau
local info = TweenInfo.new(
    0.6,
    Enum.EasingStyle.Sine,
    Enum.EasingDirection.InOut
)
```

See [`TweenInfo`](/reference/datatypes/tween-info/) for properties and defaults.

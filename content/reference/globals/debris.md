The `Debris` keyword represents the [Debris](https://create.playvortex.io/reference/classes/debris) service, which allows successful destruction of passed [Instances](https://create.playvortex.io/reference/classes/instance) within a given time frame.

It can be used to remove [Instances](https://create.playvortex.io/reference/classes/instance) without yielding the current thread. Its primary use is to free up system memory and remove objects that may no longer be needed.

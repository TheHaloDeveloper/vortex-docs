## Summary

`SpawnLocation` is available in the editor, where it behaves like a specialized Part. It is not a supported `Instance.new` target in the current Luau bridge.

Its editor controls use the same appearance, collision, and transform fields documented for [Part](/reference/classes/part/). No SpawnLocation-specific Luau members are verified.

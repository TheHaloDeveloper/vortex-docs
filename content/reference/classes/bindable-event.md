## Summary

`BindableEvent` can be created with `Instance.new("BindableEvent")`. The current build does not expose a verified `Event` signal or `Fire()` method, so it cannot yet be used like Roblox's BindableEvent from Luau.

It still inherits the common [Instance](/reference/classes/instance/) hierarchy, attribute, and lifecycle members.

## Members

No class-specific public members are verified in the current build.
